# Service Finder для WHMCS

Один рядок пошуку в адмінці WHMCS, який шукає **по всіх полях послуги одночасно**. [English](README.md)

Стандартний список послуг WHMCS фільтрує за доменом, продуктом, статусом і сервером, але не за IP, логіном панелі, нотатками чи телефоном клієнта. У реальних інсталяціях той самий IP лежить у різних полях залежно від продукту (у полі «Домен», у «Dedicated IP», у «Assigned IPs», у додатковому полі, у нотатці доповнення). Service Finder шукає в усіх одразу.

- Вільний пошук по: домену, IP (основний і додаткові), логіну, нотатках адміна, ID підписки, причині призупинення, **додаткових полях продукту**, **доповненнях**, клієнту (ім'я, компанія, e-mail, телефон), продукту, групі, серверу (назва, hostname, IP)
- Кілька слів = усі мають збігтись; `"фраза в лапках"` як одне слово
- Операції: `ip:` `status:` `server:` `product:` `client:` `user:` `id:` `old:N` (строк оплати був N і більше днів тому)
- Фільтри: статус, група продуктів, сервер
- Показує, у якому полі знайшлось, скільки днів прострочено, причину призупинення, посилання на послугу й клієнта
- Також шукає домени (реєстрації) і клієнтів
- **Лише читання**: нічого не пише в таблиці WHMCS
- Необов'язковий рушій Elasticsearch / OpenSearch (вимкнено за замовчуванням, при помилці пошук іде через SQL)

## Встановлення

1. Скопіюйте `modules/addons/servicefinder` у корінь WHMCS (`<whmcs>/modules/addons/servicefinder`).
2. Адмінка → **Налаштування → Додатки → Service Finder → Activate**, далі **Configure** і дайте доступ ролям адміністраторів.
3. Відкрийте **Додатки → Service Finder**.

Перевірено на WHMCS 9.0, PHP 8.3, MariaDB. Використовує лише стандартний API аддонів і вбудований Eloquent/Capsule, тож на 8.x має працювати, але не перевірялось.

## Приклади

```
198.51.100.66                   # будь-яка послуга з цим у домені, IP, додаткових IP чи нотатках
203.0.113                       # префікс IP
іван петренко                   # клієнт (обидва слова), по всіх його послугах
status:suspended old:60         # призупинені, строк оплати 60+ днів тому
server:vm6 product:"FTP storage"
```

`%` і `_` шукаються як звичайні символи; ввід завжди екранується й передається параметрами.

## Тести

На хості WHMCS: `php tests/run.php /шлях/до/whmcs`. Тести створюють **тимчасові таблиці** з іменами таблиць WHMCS (видимі лише сесії тесту), реальні дані не читаються й не змінюються. 80 перевірок.

## Безпека

Будь-хто, хто відкриє аддон, бачить імена, e-mail і телефони клієнтів. Обмежте доступ ролями, які вже мають доступ до даних клієнтів.
